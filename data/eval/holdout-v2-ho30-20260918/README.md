# HO30 정답 자료 봉인 — PATCH-056

상태: **수령한 정답·문항 고정, LENS 검색·생성 평가 미실시** (2026-09-18).
이번 패치의 완료는 자료 봉인 완료이며 검색 성능 검증 완료를 뜻하지 않는다.

## 파일과 사용 방법

- `review/`: 사용자가 제공한 `review.zip`의 원본 6개 파일. 바이트 단위로 보존했다.
- `questions.jsonl`: 최종 JSON에서 ID·질문만 추출한 실행 입력. 정답·검수 이력은 입력하지 않는다.
- `evaluation-contract.json`: 필수·조건부 근거와 채점 분모의 해석을 고정한다. 실행기나 자동 의미 채점기가 아니다.
- `manifest.json`: 위 파일들의 SHA-256, 수령 ZIP 해시와 당시 코드 기준점.

실행 전 `evaluation-contract.json`의 `before_first_run`에 따라 코드·데이터·모델·검색 설정·채널별 반환 개수와 지표 정의를 별도 커밋으로 고정한다. 실행 결과는 그 뒤 별도 기록한다. 이번 패치에서는 DB나 인덱스를 구축하지 않았고, 실제 보유 조문·판례와 정답을 대조하지 않았다.

## 수령 검수 결과

- HO-001~HO-030 총 30문항, 중복 ID·중복 질문 없음. 출처 50개와 참조 연결을 확인했다.
- 최종 Markdown과 JSON의 질문·답변·조건·오답 금지·채점 영향 및 근거 목록이 일치한다.
- 필수 조문 1개인 질문 19개, 복수 조문 질문 11개. 질문별 필수 조문 출현 합계는 44건이며 고유 조문 수가 아니다.
- 법령만 필수인 질문 27개, 판례·서식도 필수인 질문 3개(HO-004·008·026).
- 독립 분석 에이전트가 구조와 조건부 채점의 모호성을 재검토했다. LENS 코드·정답은 성능에 맞춰 수정하지 않았다.

### 평가할 때 반드시 구분할 점

1. 필수 목록은 **전부 확보(AND)** 조건이다. 하나만 찾은 Hit와 필수 근거 완전 확보를 구분한다.
2. 법령 부분 확보는 30문항에서 따로 산출하고 법령 전용 27문항/혼합 3문항을 나눠 보고한다. 혼합 질문의 법령만 찾고 전체 근거 확보로 기록하지 않는다. 전체 근거 확보는 판례·서식까지 포함해 30문항 기준으로 계산한다.
3. 조건부·보조 근거는 기본 검색 분모에서 제외한다. 생성 답변이 추가 설명을 했을 때 그 주장에 필요한 근거를 별도로 검사한다. 같은 출처가 필수·조건부에 중복되면 한 번만 센다.
4. **HO-009:** 긴 모범답안 전체가 최소 필수 답변은 아니다. 원본 `scoring_impact`대로 법원 명령을 전제로 한 조건부 답과 등기 방식 확인을 인정한다. 민법상 등기까지 추가 설명하지 않았다면 제3조의4 누락을 감점하지 않는다. 원본의 ‘반드시 답할 내용’ 제목을 문장별 필수 체크리스트로 변환하지 않는다.
5. 최종 기준만 사용한다. JSON의 `review1`과 변경표에 남은 과거 답·보류 판정을 현재 정답으로 사용하지 않는다. 조 단위 검색 적중과 관련 항의 실제 본문 전달 여부, 생성 답변의 정확성은 별도로 기록한다.

## 법적 근거 검토 범위와 한계

제공자는 30문항 전체의 공식 법령·판례·서식 검토 완료를 보고했다. 수령 검수에서는 전체 정답의 내부 일관성을 읽고 구조를 대조했으며, 아래 세 판례의 공식 원문을 추가 확인했다. 원본은 변경하지 않았다.

- [대법원 90다카11377](https://www.law.go.kr/LSW/precInfoP.do?evtNo=90%EB%8B%A4%EC%B9%B411377): 증액 보증금과 선행 저당권의 관계.
- [대법원 2010다42990](https://www.law.go.kr/LSW/precInfoP.do?precSeq=167313): 갱신 전 취득한 기존 보증금 우선변제권. 원본의 R 엔드포인트 대신 같은 판례의 P 엔드포인트로 확인했다.
- [대법원 2017다224630·224647](https://law.go.kr/LSW/precInfoP.do?mode=0&precSeq=197934): 상가 사건의 일반 임대차 동시이행 법리. 원본도 사실관계 차이와 특약 단정 금지를 명시한다.

일부 법령·서식 원문 URL은 이번 도구에서 다시 열리지 않았다. **이번 수령 검수가 현행 원문 50개 전체를 독립적으로 재확인한 것은 아니다.** 해당 검토 이력은 제공자의 기록을 보존한다. 원본 metadata의 상위 초안 경로·해시는 별도 자료를 받지 못해 검증하지 않았고, 이번 manifest는 실제 수령한 파일만 보증한다. 원문 HTML/PDF 전체 스냅샷이 포함된 패키지도 아니다.

## 홀드아웃의 의미

공개 저장소에 올리는 **평가 전 고정 자료**이며 비공개 블라인드 테스트가 아니다. AI 제작·정답 작성·AI 검수 자료로 사람의 법률 검수는 거치지 않았다. 제공자는 공식 Lawbot 검색을 했으며, 이는 LENS의 검색·생성 평가와 다르다. 검수자는 질문을 이미 보았고, 과거 DEV와의 완전한 독립성·중복 부재를 별도로 입증하지 않았다.

이 문항이나 측정 결과로 튜닝한 뒤에는 같은 세트를 회귀 평가로 표시한다. 오류가 확인되면 원본·버전을 보존해 정정하고 변경 전후 점수를 같은 조건의 개선으로 표현하지 않는다.
