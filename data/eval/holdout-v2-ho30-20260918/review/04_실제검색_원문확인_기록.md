# HO30 실제 검색·원문 확인 기록

확인일: **2026-09-18**. 이 기록은 리뷰2가 실제 수행한 검색·열람을 기록한다. 리뷰1의 “확인” 표시를 수행 이력으로 옮기지 않았다.

## 1. Lawbot 사용 상태

- 진입 페이지: [법제처 Lawbot](https://law.go.kr/LSW/aai/main.do). 웹 도구로 페이지 열람 후, 실제 브라우저의 검색 입력·검색 버튼을 사용해 결과 화면을 확인했다. 따라서 이번 검토는 **페이지 열람뿐 아니라 검색 실행까지 수행**했다.
- 원문 질문 30건, 쟁점별 추가 검색 17건을 실행했다. 초기에 원본 질문이 없어 초안의 쟁점으로 만든 2건은 원문 질문 검색에 포함하지 않았다. 원본을 받은 뒤 30건을 별도로 실행했다.
- 기존 조문명·번호를 그대로 넣는 Lawbot 직접 검색은 수행하지 않았다. 조문명 직접 검색 및 알려진 조문 URL 열람은 아래 국가법령정보센터·웹 검색 경로에 별도로 기록했다.
- 결과 페이지는 `https://www.law.go.kr/LSW/ais/searchList.do`로 연결되었다. 검색창에 입력한 질문과 결과 화면을 확인했다. 화면에 나타난 범위를 확인했으며 “더보기” 전체 결과나 숨은 전체 색인을 검증한 것으로 보고하지 않는다.
- 같은 브라우저 세션을 사용했다. 일부 결과 URL에는 이전 검색의 `wordListString` 값이 남아 있었다. 서버에서 이것을 어떻게 사용했는지는 확인하지 않았다. 이 수행은 법적 근거 탐색이며, 독립 세션으로 통제된 검색 정확도 실험이 아니다.
- 자연어 검색에서 민법 관련 핵심 조문이 보이지 않는 경우에도 쟁점 분리 및 공식 조문 직접 열람으로 계속 검토했다. 미검색을 법적 근거 부존재로 보지 않았다. 검색 순위·실행 결과를 정답 선정이나 holdout 기준 변경에 사용하지 않았다.

- 민간임대주택법 시행령 제40조, 민사집행법 제56조·제44조, 주택임대차보호법 시행령 제6조, 민법 제621조: 웹 열람 실패 후 실제 브라우저의 공식 개별 조문 페이지에서 본문을 확인했다.
