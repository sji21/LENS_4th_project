# PATCH-014 리뷰2 — 실제 검색·원문 확인 기록

확인일 2026-09-10. 아래 기록은 이번 신규 35문항 검토에서 실제 수행한 행위만 포함한다. 검색 결과는 후보 탐색이며 원문 확인과 구분한다. 검색 불일치·미검색을 근거 부존재로 처리하지 않았다.

## Lawbot: 페이지 열람과 검색 실행

- [법제처 Lawbot 진입 페이지](https://law.go.kr/LSW/aai/main.do)를 웹 도구로 열어 검색 입력 화면을 확인했다.
- 브라우저 도구로 같은 주소를 열었고 [지능형 법령검색 화면](https://www.law.go.kr/ais/main.do)으로 이동한 탭과 검색 입력란을 확인했다.
- 이후 이 도구 세션에서 입력·제출 조작을 진행하지 못했다. 상태 재조회 시 사용한 메서드가 지원되지 않아 오류가 났으며, 검색어 입력·검색 버튼 제출은 수행하지 않았다.
- 최종 상태: **페이지 열람 가능·검색 실행 미수행**. Lawbot에서 실제 실행한 검색어: **없음**. 페이지 접속을 검색 성공으로 집계하지 않는다.
- 대체 경로: 일반 웹검색에서 질문 자연어·쟁점별 검색 → 국가법령정보센터 법령·판결 원문 → 필요 시 법원 공식 판결 안내. Lawbot 검색 정확도·재현율을 측정한 작업이 아니다.

## 검색 종류와 기록 단위

- 대체 웹 도구 기록 35회, 검색 요청 문구 58개. 원문 질문 전체를 포함한 검색 35개(문항별 1개). 한 번의 도구 요청에 여러 검색·열람이 묶일 수 있어 호출 수와 검색어 수는 다르다.
- 처음에는 질문·상황을 바탕으로 쟁점을 묶어 자연어 검색하고, 이어 각 질문 원문에 공식 도메인 제한을 붙여 35개를 검색했다. 이후 조문명·사건번호 직접 검색과 원문 링크 열람으로 검증했다.
- “원문 질문 검색”도 Lawbot이 아니라 대체 웹검색이다. 032의 짧은 질문은 질문 단독 탐색이며 이전 대화의 지급자 정보는 법적 판단 때 별도로 대조했다.
- 아래 검색어는 그대로 기재한다. 검색 스니펫만 나타난 페이지를 전부 원문 확인으로 표시하지 않는다. 원문 채택 범위는 다음 출처대장이 우선한다.
