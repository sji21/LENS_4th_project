# 팀 공유 개발용 100문항 v1

범위 점검·검색 개선에 사용하는 공개 개발셋이다. 독립 평가셋이 아니다. 평가 기준일은 2026-09-08이며, 이후 법령·기관 안내의 유효성을 자동 보증하지 않는다.

- `questions.json`: 문항 ID·질문·원래 제공 상황·영역, 실제 검색에 사용한 두 입력 문자열. `question_only`와 `context_diagnostic`의 `query`를 그대로 사용한다. 문맥 입력은 앱의 대화 재작성/OCR 성능 평가가 아니다.
- `gold-review.md`: 사용자가 제공한 2번 AI 정답 검토 보완본 원문. 서비스 범위, 질문, 결론, 공식 출처, 조건과 불확실성, 보완 부록을 포함한다. 부록의 26개 수정이 본문보다 우선한다.
- `requirements.json`: 부록 26개를 반영한 100문항의 유효 근거 목록. 필수·조건부·대체·보조와 사실·행동 조건을 보존한다. `formal_score_ready=false`는 최종 AND/OR 채점식이 아니라는 뜻이다.
- `pre_patch008_law_rankings.json`: 이전 공개 개발 실행의 법령 청크 ID 순위. 전후 관측용이며 질문 입력이나 정답 라벨로 사용하지 않는다.
- `manifest.json`: 위 파일의 SHA-256 및 버전 정보. 질문·정답 변경 시 새 버전으로 보존하고 변경 이유를 기록한다.

100문항과 검색 입력 200개는 기존 실행과 일치한다. 정답 검토 원문·유효 근거 JSON은 원본 바이트를 보존했다. 합성 문서·가명·질문 속 가상 금액은 질문의 일부다. 비밀값, 주민등록번호 및 개인 휴대전화번호 패턴 검사에서 탐지되지 않았다.

## 실행

저장소 루트에서 프로젝트 의존성과 로컬 임베딩 모델, PATCH-008 기준의 운영 DB·청크·기본 및 민법 Chroma 인덱스를 준비한다. 데이터 준비는 `docs/patch006-civil-routing.md` 및 `docs/patch008-civil-rollout.md`를 참고한다. 이 입력셋을 추가해도 대용량 DB·벡터가 Git에 포함되지는 않는다.

```powershell
.venv/Scripts/python scripts/dev100_diagnostics/capture.py --out tmp/dev100-team-run
.venv/Scripts/python scripts/dev100_diagnostics/report.py --run-dir tmp/dev100-team-run
```

새 출력 경로를 사용한다. 캡처는 기존 폴더를 덮어쓰지 않으며, 원본 데이터 대신 복사본으로 검색한다. 현재 검증기는 기본 165건 + 민법 7건 기준이므로 코퍼스를 확대한 후에는 새 기준선과 검증 조건을 명시적으로 갱신해야 한다.

법령 인용이 모두 있다는 사실과 필요한 근거를 검색했다는 사실은 다르다. 정답 일부 미확인 11문항은 그대로 표시하고, 정보 부족 문항을 일괄 실패나 제외로 처리하지 않는다. LLM 답변 품질은 별도 평가한다.
