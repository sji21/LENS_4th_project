# 주택 임대차계약서 작성 항목·특약 점검

## 기능 범위

사용자가 전세·월세 주택 임대차계약서 PDF 또는 휴대폰 촬영 JPG·JPEG·PNG를 업로드하면 PDF 내장 텍스트 추출과 로컬 Tesseract OCR을 이용해 다음 내용을 점검한다.

```text
계약서 PDF 또는 촬영 이미지
  → 파일 형식·20MB 제한 검증
  → PDF: 페이지 검증과 내장 텍스트 우선 추출
  → PDF 스캔 페이지: 필요한 페이지만 Tesseract OCR
  → JPG·JPEG·PNG: 4천만 픽셀 제한과 EXIF 회전 보정 후 Tesseract OCR
  → 주택 임대차계약서 여부 확인
  → 핵심 작성 라벨과 값 탐지
  → 특약 개념 문구 탐지
  → 누락 가능 항목·협의할 특약·공식 출처 표시
```

외부 OCR API나 LLM을 사용하지 않으며 업로드 원본과 OCR 전체 문장을 서버 파일이나 공용 Vector DB에 저장하지 않는다.

촬영본은 한 이미지당 계약서 한 페이지로 처리한다. 여러 페이지라면 페이지별 사진을 하나의 PDF로 합치거나 현재 화면에서 한 장씩 점검해야 한다. 정면에서 문서 전체가 나오도록 촬영하고 그림자·빛 반사·기울어짐·흔들림을 줄여야 OCR 미탐지를 줄일 수 있다.

## 항목 상태

| 상태 | 의미 |
| --- | --- |
| 작성값 탐지 | 항목 라벨 주변에서 금액·날짜·주소 등 값 형태를 함께 찾음 |
| 원본 확인 | 라벨은 찾았지만 작성값을 명확하게 판독하지 못했거나 서명·도장처럼 육안 확인이 필요함 |
| 미탐지 | OCR에서 항목 라벨을 찾지 못함. 실제 공란이나 누락을 확정하는 상태가 아님 |
| 판독 보류 | 텍스트가 없거나 주택 임대차계약서로 확인할 근거가 부족함 |

표준 서식의 빈 라벨만 발견된 경우 작성 완료로 처리하지 않는다. 자필 서명과 도장은 OCR로 존재를 확정할 수 없으므로 항상 원본 육안 확인을 요청한다.

## 핵심 확인 항목

- 임대 목적물의 주소
- 임차 부분·동·호·면적
- 임대인과 임차인의 인적사항
- 보증금
- 월 차임(월세 계약인 경우)
- 계약금·중도금·잔금과 지급 일정
- 임대차 기간
- 실제 계약 체결일
- 당사자의 서명·날인
- 공인중개사 정보(중개 거래인 경우)

항목 기준은 HUG의 계약내용 확인 안내와 국토교통부 주택 임대차계약 신고 입력 항목을 바탕으로 한다. 탐지 결과만으로 계약의 성립이나 효력을 판단하지 않는다.

## 특약 점검

현재 다음 개념의 문구 포함 여부를 점검하고, 찾지 못하면 당사자와 협의할 내용을 제안한다.

1. 계약 후 잔금·입주·전입신고 효력 발생 전까지 새로운 담보권이나 소유권 이전 등 권리변동 제한
2. 기존 근저당·신탁·전세권 등을 말소하기로 한 경우 대상 권리, 기한과 불이행 시 처리
3. 임차인의 책임 없이 전세보증금반환보증에 가입하지 못할 경우 계약과 지급금 처리
4. 선순위보증금·세금 체납·권리관계 고지 내용이 사실과 다를 경우의 처리
5. 수리·도배·누수·곰팡이·옵션 상태와 비용 부담 주체

추천 내용은 계약서에 자동 삽입하는 법률 문안이 아니다. 실제 등기 상태, 주택 유형, 전세·월세 구분과 당사자 합의에 따라 구체화하고 필요한 경우 공인중개사 또는 법률 전문가의 검토를 받아야 한다.

앞서 같은 세션에서 등기 PDF를 점검했다면 근저당·신탁·전세권·임차권등기 신호와 기존 권리 말소 특약을 연결해 우선 확인 대상으로 표시한다.

## 한계와 안전장치

- OCR은 손글씨, 도장, 체크 표시, 표의 빈칸과 취소선을 정확하게 판독하지 못할 수 있다.
- 촬영 이미지의 심한 원근 왜곡·빛 반사·낮은 해상도는 현재 자동 보정하지 않으며, EXIF 방향 정보에 따른 회전만 보정한다.
- 라벨 주변에서 값 형태를 찾았다는 것이 해당 값의 정확성이나 당사자 합의를 보장하지 않는다.
- 이름·주소·계좌번호·서명 등은 화면에서 원본 대조에 필요한 최소 범위로만 확인한다.
- 다운로드 JSON에는 파일명, OCR 원문, 텍스트 미리보기와 항목별 근거 문구를 포함하지 않는다.
- 계약 내용과 등기상 소유자·주소·권리관계의 실제 일치 여부는 현재 자동 교차검증하지 않는다.
- 추천 특약이 모든 계약에 필요한 것은 아니며 특약만으로 보증금 회수가 보장되지 않는다.
