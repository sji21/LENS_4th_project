## 4. 최종 조합의 실검색 검증

1. 실행 전에 정책·반환 개수·전체 실행 코드·의존성 해시를 execution-spec.json에 기록했다.

3. **별도 단계에서 미튜닝 검색기와 실험용 검색기를 각각235회 새로 호출했다.** 실험용 검색기는 기존 RetrievalService.search 흐름·결과 형식을 사용하고 일반/민법 검색을 실험 정책으로 대체한다. 운영에 연결한 것은 아니다.
4. 실제 인덱스의 문서·메타데이터와 후보 청크를 대조한 뒤, 실험 결과 총3,089개 근거의 ID·순위·원문 해시·인용명·URL·자료 유형을 확인했다.
5. 미튜닝 기존 결과와 실검색235건, 재조합과 실험용 검색235건이 각각 일치했다. 판례·안내도235건 모두 순위·원문·출처가 동일했다. 후보 DB·청크·인덱스의 보존을 확인했다.

최종 일반 Hit1·3·5는 질문17·34·36/47, 문맥17·33·39/47이다. 민법 Hit1·3은 질문18·23/32, 문맥14·21/32다. 같은 분모의 Hit1≤Hit3≤Hit5를 확인했다. DEV의 고정 정답 없음23개·과거 판본 보류2개와 CIV35의 별도 범위1개·진단5개는 별도 집계한다.

신규 고정 필수 근거는 일반17개+민법9개, 합계26개가 해당 정답 입력에 등장했다. 민법9/9는 **고유 조문 기준**으로, 모든 관련 문항의 완전 성공을 뜻하지 않는다.
