# PATCH-027 검색 개념 확장 튜닝

## 실행 전 고정한 비교

이 작업은 공개 DEV100·CIV35의 실패 분석에 따른 개발 튜닝이다. 기존 같은235입력,204조문, KURE-v1, 일반5·민법3·판례5·안내0~2, 정답·채점 분모를 유지한다. 결과를 본 뒤 문항별 조문을 고정하거나 정답을 바꾸지 않는다.

가설: 일상 표현을 조문 용어로 연결하면 신규 민법의 낮은 후보 순위를 개선할 수 있다. 검색 확장어는 법적 판단·생성 근거로 쓰지 않고 검색 질의에만 붙인다. 본문과 벡터는 고치지 않으며 같은 Chroma 인덱스로 확장 질의를 검색한다. BM25+KURE 하이브리드는 유지한다.

일반 법령 대안4개:
- `lexical`: 새 개념을 BM25 확장어에만 추가. KURE는 원질문.
- `both`: 같은 BM25 확장과 KURE 질의에도 개념 추가.
- `blend`: 원질문 하이브리드20위와 `both`20위를 RRF 동일 비중으로 재결합.
- `core3_blend`: 기존 임대차 묶음 TOP3를 먼저 보존하고 `blend`로 나머지2칸 보충.

민법 대안4개:
- `lexical`: 새 개념을 BM25에만 추가, 기존 주제 선택과 세 번째 후보 보충 방식 유지.
- `both`: KURE 질의에도 개념을 추가, 나머지는 `lexical`과 동일.
- `plain_both`: `both` 결합 TOP3를 그대로 사용, 기존 주제 선택을 생략.
- `seed1_both`: 기존 주제 선택은 최대1개만 유지하고 `both`로 보충. 세 번째 후보는 기존 의미검색2배 방식.

두 채널을 각각 현재204조문 결과에 대해 비교하고, **`core3_blend + seed1_both` 조합1개도 사전에 지정**한다. 비교 후 유리한 조합을 추가 탐색하지 않는다. 선택기는 질문 ID·정답 ID를 읽지 않으며, 신규 개념 사전은 조문 ID 없이 문자열·문맥 신호로 검색어만 반환한다. 기존 주제 선택 자체의 조문 지정은 제품 기준선으로 보존한다.

채택 기준은 [직전 비교](patch027-law-expansion.md)의 기준을 유지한다. 기존143조문 대비 일반 TOP3·실제 반환 합집합의 필수 근거 손실0, 완전 확보32/75·34/75 이상, CIV35 완전 확보28/29·민법 Hit3 29/29 보존이다. 개선 여부와 채택 여부를 분리해 보고한다. 통과하지 못한 튜닝을 운영에 적용하지 않는다.

개념 사전도 DEV 실패를 본 뒤 작성한 것이므로 독립 성능을 주장할 수 없다. 합성 표현 변형 테스트는 규칙 검증일 뿐 새로운 독립 평가셋이 아니다. 사용자 발화의 부정·인용·이전 대화를 깊게 구분하지 않는 문자열 규칙이라는 한계가 있다.
