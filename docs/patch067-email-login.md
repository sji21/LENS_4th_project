# PATCH-067 이메일 로그인

## 목적

회원가입에서 이미 수집하고 대소문자 구분 없이 고유하게 관리하는 이메일을 로그인 식별자로 사용한다. 사용자에게 내부 계정 아이디를 다시 기억하게 하지 않는다.

## 동작

- 로그인 화면은 이메일과 비밀번호를 받는다.
- 입력 이메일은 대소문자를 구분하지 않고 기존 회원의 이메일과 대조한다.
- 인증에는 해당 회원의 기존 `username`을 내부적으로 전달하므로, 기존 사용자·비밀번호 해시·Django 권한 데이터의 마이그레이션은 필요 없다.
- 이메일이 아닌 기존 아이디를 입력하면 이메일 형식 오류를 표시한다.
- 로그인 성공 뒤 채팅 홈 이동과 현재 브라우저의 게스트 대화 연결은 기존과 같다.

## 범위와 제한

- 이메일 로그인은 일반 Django 로그인 경로(`/accounts/login/`)에만 적용한다.
- 회원가입의 아이디 입력은 기존 데이터 및 내부 식별자 호환성을 위해 유지한다.
- 비밀번호 재설정·소셜 로그인·이메일 인증 발송은 이번 범위에 포함하지 않는다.

## 검증

- 이메일 대소문자 변형 로그인, 아이디 로그인 거부, 로그인 후 채팅 이동, 게스트 대화 연결을 회귀 검사한다.
- 실행: `.venv311/bin/python -m pytest tests/test_case_features.py tests/test_patch045_review_fixes.py -q`
- Django 설정 검사: `.venv311/bin/python manage.py check`
