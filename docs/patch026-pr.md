# PR 제목

feat(retrieval): DEV100 법령 보완·일괄 후보 적재·검색 평가 (PATCH-026)

# PR 본문

## 목적과 범위

DEV100 검토본이 요구하는 법령을 전체 조사·후보 적재한 뒤 검색 영향을 검증합니다.
현재 초기5조문 후보 외에 미보유44조문(고정 필수27·기타 검토 참조17)과 자료 종류·조문·판본
식별이 필요한6건을 확인했습니다. 아직 신규44조문의 공식 원문 검증·적재는 수행하지 않았습니다.
전체 데이터 확보를 5조문만의 추가 튜닝보다 우선합니다.
데이터 선정·후보 적재·검색 보완·재평가를 PATCH-026 하나로 묶었습니다.
별도 등록했던 PATCH-027의 커밋을 재작성 없이 통합했으며 별도 PR은 만들지 않습니다.

초기 실험 대상은 주민등록법 제16조, 국세징수법 제109조·동 시행령 제97조,
지방세징수법 제6조·동 시행령 제8조입니다. 공식 조문 원문·판본·해시·적재 레코드를 공유합니다.
PATCH-025에 의존하며 관련 GitHub 이슈는 없습니다.

## 초기5조문 구현과 평가 — 전체 코퍼스 결과 아님

- DB·인덱스 사본에서 전체 5개/체납 4개/전입 1개를 각각 추가해 동일 235입력으로 평가했습니다.
  기존 검색에 그대로 혼합하면 기존 필수 TOP5 근거 손실이 각각 6/4/1개였습니다.
- 같은 5개 데이터로 통계 변화와 후보 경쟁을 분리하고 7개 검색 결합 정책을 비교했습니다.
- 기존/절차 BM25 통계를 분리하고 원점수를 같은 비중으로 합친 뒤 기존 dense/RRF로
  결합하는 후보를 구현했습니다. 기존 DB에서는 원래 검색기를 사용합니다.
- 일반 법령 TOP5, 민법 최대3, 판례·안내 반환 계약을 유지하며 모델·생성 채널을 추가하지 않습니다.

| 항목 | 기존 | 검색 보완 후보 |
| --- | ---: | ---: |
| DEV 질문 필수 근거 완전 확보 | 28 | 29 |
| DEV 문맥 포함 필수 근거 완전 확보 | 30 | 31 |
| 일반 법령 Hit@3: 질문 | 22/47 | 26/47 |
| 일반 법령 Hit@3: 문맥 | 23/47 | 25/47 |
| 기존 필수 TOP5 근거 손실 입력 | 0 | 0 |

실제 검색 235입력이 선택 후보와 모두 일치하고 민법·판례·안내 출력은 보존됐습니다.
일반 법령 Hit@1은 질문15/47, 문맥13/47로 유지됩니다. 공개 개발 자료이며 독립 평가가 아닙니다.

## 현재 남은 작업 — 최종 반영 준비 미완료

**DEV-044 질문 입력에서 기존 필수 근거가 3위→4위로 내려갑니다.** 평균 Hit@3 상승과
개별 TOP3 회귀는 동시에 발생합니다. 법령 앞의 3개만 사용하는 생성 경로에 영향이 있으므로
운영 데이터 추가 적재는 보류합니다. 먼저 전체 추가 대상의 원문·판본을 확인하고 하나의 사본에
적재한 뒤235입력을 다시 평가합니다. 이 회귀와 최종 반영 판단까지 같은 PATCH-026에서 진행합니다.
현재는 검토용 초안이며 최종 병합 준비 완료로 표시하지 않습니다.
