# PATCH-022: F-06 항 인용 검증

## 문제와 변경

다른 조문의 제5항이나 제3조의3의 제1항을 현재 제3조의 해당 항으로 인정하던 검증을 수정했다. 답변에서 법령명이 명시된 법령·조·가지번호를 기존 citation 모듈의 식별 규칙으로 읽고 검색 근거 citation과 정확히 연결한다. 인용 모듈 자체의 동작은 변경하지 않았다. 법령명이 빠졌거나 헤더가 citation과 충돌하면 확인 불가로 처리한다.

근거 자체의 줄 시작 원문자 항 표지를 확인한다. 첫 항부터 연속된 번호만 인정하며 인용문·코드 블록·인용 블록은 제외한다. 여러 조문 제목이 섞였거나 설명문으로 시작하는 발췌, 번호가 누락·중복된 발췌는 보수적으로 확인 불가로 처리한다. 따라서 단순 본문 속 제N항 문자열은 항 존재 증거가 아니다.

`answer.evidences` 경로를 유지해 일반 법령과 civil_laws를 모두 검사한다. 잘못된 항 인용은 기존 paragraph 이슈로 보고되어 chain과 graph의 최종 답변 보류로 이어진다.

## 범위와 한계

- 이 검증은 검색 근거에서 해당 항 번호를 확인하는 것이며 법적 주장 전체의 타당성 판단이 아니다.
- 번호 없는 조문을 제1항으로 추정하지 않는다. 평문이나 부분 발췌의 정확한 항도 확인 불가가 될 수 있다.
- 현재 Evidence에는 구조·판본 필드가 없다. DB 구조와 다른 판본을 조회하거나 위치값을 적용하지 않으므로 다른 판본 구조로 누락을 보충하지 않는다. 법령 판본의 최신성·정확성 자체를 검증한 것은 아니다.
- DB·인덱스·검색 순위·코퍼스는 변경하지 않는다. 법령 구조 파서의 DB 원문 오프셋을 검색용 본문에 재사용하지 않는다.
