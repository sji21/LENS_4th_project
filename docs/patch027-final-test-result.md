## 2. 마지막 보완의 효과와 한계

확정일자 기록·부여 여부를 확인하려는 현재 요청을 보호 효과 질문과 구분했다. 바로 다음 문장의 ‘예전/그때/당시 기록’ 참조도 대상이 연결될 때만 사용한다. 이전 대화, 인용된 예문, 다른 수리 기록, 보호 효과 질문은 새 확장을 발동시키지 않는 반례로 검사했다. 정답 조문·DEV 번호를 검색 조건에 넣지 않았다.

235입력 중 일반 법령 결과가 달라진 것은 **DEV-099 질문과 문맥2입력**이다. 민법·판례·안내는 앞선 검증 조합과 동일하다.

- 질문: 주택임대차보호법3의6이3위→1위.
- 문맥: 해당 근거가 TOP5 밖→5위로 회복. 기존 운영 대비 반환 손실8→7, 문맥 완전 확보42→43.
- 다만 문맥 근거는 아직 TOP3 밖이다. 따라서 일반3+민법3 소비 진단은38/75로 그대로다. 이를 LLM 입력 개선1건이나 최종 답변 개선으로 과장하지 않는다.

두 후보 모두 사전 정량 조건을 통과했다. 고정 선택 규칙에서 완전 확보 합계가 더 큰 `record_lookup`을 골랐고, 추가 튜닝이나 합격선 변경은 하지 않았다.

최종 반환 손실7과 일반 TOP3 손실7은4입력이 중복되어 합집합10입력이다. TOP3만 손실인 DEV-005 질문·DEV-049 문맥·DEV-088 문맥은 필요한 해당 근거가 TOP5에는 남아 있다. DEV-088 문맥은 새 필수 근거가 추가되어 TOP5 전체는 새로 완성됐지만 TOP3 소비의 한계는 남는다.

이 손실들은 실제 검색의 제약이다. 다른 조문이 법적으로 대체 가능하다고 임의 판정하거나, 답변이 안전하다고 단정하지 않았다. source/조문 오연결과 본문 변조는 없음을 검증했지만, 근거 누락의 법적 심각성 전체를 자동 판정한 결과는 아니다.
