# PATCH-027 잔여 근거 손실 분석과 개선 가능성

상태: 분석·오프라인 선택 비교 완료, 운영 미채택 / 2026-09-13

사용자 요청으로 기존 손실0 기준의 영향과 개선 가능성을 추가 확인한다. 기존 실험 결과·정답·채택 기준은 바꾸지 않는다. 기준을 제안한 주체는 리트리버 튜닝 계획을 작성한 AI이며, 사용자나 팀이 반드시 지켜야 한다고 직접 지정한 요구사항으로 취급하지 않는다.

## 실행 전에 정한 비교 범위

- 기존 반환 손실8입력과 일반 TOP3 손실7입력의 중복을 제거하고, 실제 필수 근거 누락/순위만 하락/완전 확보 유지·악화를 구분한다.
- 후보 단계의 BM25·KURE·RRF 순위와 최종 선택을 대조한다. 평가 정답의 법적 적합성이나 대체 근거 인정은 임의로 재판정하지 않는다.
- 선택 정책 반사실 비교는 **1개만** 수행한다. 명시적 민법 주제 seed와 준용 보충이 모두 없는 경우 RRF TOP3를 유지하고, 세 번째 슬롯의 dense 추가 가중치를 생략한다. 나머지 조건·질의·일반 법령·반환 개수는 그대로 둔다.
- 같은235입력 전체에서 이득과 새 손실을 함께 센다. 특정 DEV 번호·조문 ID로 반환을 강제하지 않는다. 이 비교는 저장된 실검색 구성원 순위의 재조합이며 운영 적용이나 새 실검색 검증으로 표현하지 않는다.
- 일반 법령의 명확한 문맥 오인은 원인을 설명하고, 필요하면 원인 하나를 제거한 제한된 진단 검색으로 가능성을 확인한다. 새 성능으로 주장하려면 전체 입력·실제 검색 검증이 별도로 필요하다.

## 결론

**개선할 여지는 있다. 손실 8입력의 필수 조문은 모두 후보 검색에 들어왔고, 주로 결합 순위와 최종 선택에서 밀렸다.** 다만 민법 선택 규칙 하나를 제거한 비교는 2입력에서 필수 조문을 되찾는 대신 다른 1입력에서 잃었다. 이를 안전한 해결책이나 운영 성능 개선으로 채택하지 않는다.

기존 반환 손실8 + 일반 TOP3 손실7은 15개의 서로 다른 실패가 아니다. 4입력이 겹쳐 **11입력**이며, 이 중3입력은 목표가 TOP5에 남아 있다. 다른 근거가 그 법적 주장을 대체할 수 있는지는 정답 검토 범위이므로 이번 분석에서 인정하거나 점수를 고치지 않았다.

**저장된 실검색 구성원 순위로235입력을 재조합한 결과이며 새로운 실검색은 하지 않았다.** 운영 DB·인덱스·검색 코드를 수정하지 않았다.

## 다음 개선 우선순위

1. **현재 요청과 필요한 이전 사실을 구분한 검색 입력.** DEV-010·059와099를 함께 사용해 필요한 사실 생략과 문맥 과잉을 모두 검사한다. 실제 제공된 사실만 사용하고 정답 표현을 질문에 주입하지 않는다. 사용자 질문만으로 알 수 없는 사실을 추정하거나, 후속 질문을 평가에서 삭제하지 않는다.
2. **적용 범위·대리 권한·기록 조회 의도의 후보 순위.** DEV-009·012·099는 dense 상위 근거 또는 기존 단독 질문의 근거가 결합/확장 후 밀린다. 주거·상가 혼합, 대리 확인, 기록 조회와 보호 효과 구분에 대한 독립적인 변형·반례를 먼저 준비한다. 특정 조문이나 문항을 강제로 올리는 규칙을 만들지 않는다.
3. **마지막 민법 슬롯은 일괄 변경하지 않는다.** 이번 후보는059 회복 대신058 손실을 만들었다. 의미에 근거한 후보 선택을 검토하되,627 보존을 위해 또 다른 조문 고정 예외를 붙이는 방식은 피한다.

새 정책은 개발 결과를 보고 만든 것이므로 개발 튜닝으로 표시하고,235입력 전체의 완전 확보·Hit1/3/5·기존 손실·새 손실을 함께 비교한 뒤 실제 검색기로 확인한다. 일반 TOP3만 소비하는 현재 연결도 별도 지표로 유지한다. 다음 실험의 채택 기준은 실행 전에 사용자/팀과 정한다. 이번 결과에 맞춰 기존 기준을 소급 변경하거나 ‘손실0’을 팀의 의무로 확정하지 않는다.
