## 지표와 실패 분석

1. 채널별 Hit@K(필수 중 하나 이상), 문항별 Recall의 평균, 필수 근거 출현 기준 micro Recall, 필수 모두 확보(AND), MRR를 구분한다. 일반 법령 K3 실행과 K5 실행의 지표는 실행별로 표시한다.
   채널 분모는 해당 채널의 필수 정답이 있는 문항으로 한정한다(HO 일반19·민법11·판례2·서식1). 빈 정답 채널을 성공 또는 Recall0으로 평균에 넣지 않는다. MRR은 해당 반환 깊이에서 첫 정답의 역순위이며 미반환은0이다.
2. 서로 다른 채널의 순위를 합치지 않는다. 법령+민법 완전 확보는 명시한 채널 예산의 집합 합으로 계산한다. 판례·서식이 필요한 HO 문항의 법령 확보를 전체 성공이라고 하지 않는다.
3. K는 먼저 실제 반환 위치에 적용하고 그 뒤 동일 조문·사건을 중복 제거한다. 법령명+조번호·가지번호를 보존한다. 관련 항 본문·근거 텍스트는 저장하되 조 단위 적중을 항별 의미 검증으로 확대 해석하지 않는다.
4. 문항별 필수 근거, 보유 여부, 반환 위치·본문·출처, 단계형 포함 여부, 과거 대비 근거 손실을 기록한다. 미보유/검색 후보 누락/순위·선택 누락/단계형 미전달/채점 보류를 구분한다.
   판례 매핑이 불명확하면 전체 분모를 유지한 보수적 하한과 매핑 보류 수를 명시하고 확정 점수와 구분한다. 후보 추적을 보관하지 못한 채널에서는 후보 누락과 최종 선택 누락을 단정하지 않고 상세 원인 미확인으로 남긴다.
5. 실제 검색 요청 지연과 모델·인덱스 초기 로딩 시간을 분리한다. 같은 PC·실행조건의 참고값이며 과거 CPU·RunPod 결과와 속도 개선률을 계산하지 않는다.
