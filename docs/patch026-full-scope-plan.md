# PATCH-026 전체 법령 적재 범위와 진행 순서

2026-09-13: 일부 5조문의 튜닝을 먼저 마무리하던 순서에서, 검토된 전체 법령 자료를 먼저 확인·후보 적재한 뒤 검색을 평가하는 순서로 변경한다.

## 확인된 범위

- 기존 운영 기준: 143조문. 현재 5조문 평가 사본: 148조문.
- 고정 필수 근거 미보유 23문항 → 중복 제거한 추가 조문 27개.
- 검토본의 다른 조건부·보조 등 참조에서 미보유 조문 17개 추가.
- 현재 조문 식별자가 있는 추가 확인 대상: 총44조문. 전부 적재 가능하다고 확정한 수가 아니다.
- 단일 조문으로 정규화되지 않은 law 분류 자료6건은 자료 종류·조문·판본부터 확인한다.
- 별도 판례9건·기관 안내7건의 검토 참조도 있으므로, 법령 조문 확보를 서비스 전체 데이터 완료로 표현하지 않는다.

## 진행 순서

1. 44조문과 미정리6건의 공식 원문·시행판본·검토 제한을 대조한다. 기존5개도 같은 전체 목록에 포함한다.
2. 확인된 전체 법령을 하나의 DB·청크·인덱스 사본에 적재한다. 민법은 기존 별도 채널로 연결하고, 적재했지만 검색 허용 목록에서 빠지는 일이 없는지 확인한다.
3. 조·항·호·목 구조, 출처·판본, 기존 본문 보존, DB·청크·인덱스의 일치를 검사한다.
4. 완성된 후보 코퍼스로 동일235입력을 평가하고 미보유·검색 실패·순위 하락을 구분한다. 고정 정답은 그대로 두며 조건부 근거를 임의로 필수 정답으로 바꾸지 않는다.
5. 그 결과를 기준으로 필요한 검색 보완을 같은 PATCH-026에서 진행한다. DEV-044도 전체 코퍼스 결과에서 다시 본다.
6. 기존 TOP3/TOP5 근거 보존·신규 확보·다른 채널 영향으로 최종 반영 여부를 판단하고 PR 하나로 정리한다.

평가 기준일이나 근거 역할이 불명확한 자료는 확인 대기 목록에 남긴다. 법령으로 분류된 기관 안내나 과거 판본을 현행 조문으로 임의 적재하지 않는다. 원본 검토 제한과 채점 분모도 유지한다.
