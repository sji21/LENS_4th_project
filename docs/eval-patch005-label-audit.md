# PATCH-005 법령 Dev 라벨 감사 결과

검토일: 2026-09-08. 담당: sji21 (AI 보조 검토).

## 결론과 범위

이관된 `eval-audit.md`의 11개 미체크 항목은 현재 평가셋의 미수정 항목 목록이 아니다.
3개는 3차에서 이미 수정됐고, 나머지 8개는 아래 코퍼스 대조 근거로 현재 라벨을 유지한다.
이번 패치에서 질문·gold_articles·answer_type·코퍼스·검색 코드는 변경하지 않는다.
따라서 새 평가셋 버전이나 성능 재측정은 만들지 않는다. 기존 100%는 기존 공개 Dev의
회귀 수치이며, 이 문서가 독립 평가나 전문가 법률 검수를 추가한 것은 아니다.

판정란 누락과 실제 라벨 정정 누락을 구분한다. 3차에서 11문항 모두를 사람이 최종 승인했다는 기록은 확인하지 못했다.

## 11문항 판정

아래 조문 번호는 별도 표기가 없으면 주택임대차보호법이다. 근거는 현재 고정 코퍼스의
해당 `article_id` 본문을 직접 대조한 것이다. 검색 순위는 판정 근거로 사용하지 않았다.

추가하고 `answerable`로 바꾼 사실을 확인했다. 이번 패치의 추가 수정 대상은 아니다.

## 자료와 검증 한계

- 대조 파일: `data/chunks/chunks.jsonl`, `data/chunks/guides.jsonl`. PATCH-002에 기록된 기준선 산출물이다. 법령 청크의 시행일 메타데이터는 2026-01-02, 시행령은 2026-07-01이다.
- 공식 출처: [국가법령정보센터 주택임대차보호법](https://www.law.go.kr/LSW/lsInfoP.do?lsiSeq=276291). 웹에서는 시행 2026-01-02·법률 제21065호 표기를 확인했으나 본문이 도구에 제공되지 않아, 위 항별 대조는 로컬 고정 코퍼스에 근거한다. 현행 원문 전체와 코퍼스의 일치 검증으로 해석하지 않는다.
- 기관 안내 원출처는 청크에 기록된 [국세청 안내](https://www.nts.go.kr/nts/na/ntt/selectNttInfo.do?nttSn=1325154&mi=2207)이며, 이번 검토에서 해당 웹페이지를 새로 수집하지 않았다.
- 23/24 관측의 원인을 라벨에 연결할 증거는 없다. 이번 감사는 그 현상의 원인 분석이 아니다.
- 검증: 감사 대상 11개와 현재 데이터의 qid 일치, 법령·안내 정답 ID의 코퍼스 존재, 3차 정정본과 현재 평가셋 blob 동일성, 코드·평가 데이터 변경 없음 확인. 문서만 변경하므로 전체 테스트와 검색 재측정은 실행하지 않는다.
- 향후 질문 의미·정답·분류를 변경할 경우 기존 평가셋을 보존한 새 버전을 만들고 별도로 재평가한다. 기존 100%와 다른 라벨의 점수를 동일 조건 향상으로 비교하지 않는다.
