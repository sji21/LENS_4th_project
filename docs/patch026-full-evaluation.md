# PATCH-026 전체 법령 적재·평가·분석

2026-09-13. **검토된 현행 법령의 고정 필수 조문 미보유는 해소했으나, 순위 회귀가 있어 운영 반영은 보류한다.**

## 무엇을 적재했나

초기 절차법 5개 + 추가 확인 44개 + 미정리 참조에서 식별한 12개 = **61개 추가**다. 마지막 12개에는 확정일자 규칙 8개, 민간임대법 제44조의2·시행규칙 제18조, 공공주택법 시행규칙 제13·25조가 포함된다. 판본·제외 자료는 [출처 검토](patch026-full-sources.md), 전체 목록은 [고정 명세](../data/eval/patch026-full/specs.json)를 따른다.

후보 민법 검색 허용 목록도 26개로 늘려 실제 검색에 연결했다. 질의별 예외·가중치·반환 수를 새로 튜닝하지 않았다. 일반 법령은 기존 PATCH-026의 5개 절차법 제목에 대한 BM25 통계 분리를 유지하고, 이번 나머지 일반 법령은 기존 일반 묶음에 추가했다.

기존 적재기는 판본 전체를 교체하므로, 민법 추가 시 기존 10개 레코드를 함께 전달하도록 평가 실행기를 보완했다. 사본의 기존 조문 본문·출처·세부 구조는 모두 보존됐다. 기존 민법 SQL 청크 10개의 `created_at`만 재적재 시각으로 바뀌었으며 본문·토큰 수·체크섬은 동일하다. 운영 DB와 기존 검색 벡터는 변경하지 않았다.

## 같은 100문항의 전후 비교

한 문항의 고정 필수 조문을 **일반 법령 TOP5 + 민법 TOP3에서 모두 반환**하면 완전 확보로 센다. 실제 사용자 질문만 넣는 측정과 제공 상황·문서를 붙인 진단을 구분한다.

| 분류 | 질문: 기존 | 질문: 후보 | 문맥: 기존 | 문맥: 후보 |
| --- | ---: | ---: | ---: | ---: |
| 필수 근거 모두 반환 | 28 | **32** | 30 | **34** |
| 필요한 데이터 미보유 | 32 | **0** | 32 | **0** |

| 과거 판본 검토 보류 | 2 | 2 | 2 | 2 |

공식 조문 채점 분모는 75문항이다. 질문·문맥 모두 **새 완전 확보 9개, 기존 성공 상실 5개 → 순증 4개**다. 데이터 공백이 사라졌다고 검색 성공으로 처리하지 않았다. 43/41개는 고정 근거의 검색 누락이며, 반환된 모든 조문이 법적으로 틀렸다는 뜻은 아니다.

고정 필수 기준의 미보유 0은 현재 검토된 조문 목록에 한정된다. 과거 판본·유형별 별표·판례·기관 안내·상품 약관을 포함한 서비스 전체 데이터가 완비됐다는 뜻은 아니다.

## TOP1·3·5

아래 Hit는 해당 채널의 필수 근거 중 **하나 이상**을 반환한 문항 수다. 위의 모든 필수 근거 확보와 다르다. 분모를 전후 동일하게 고정했다.

| 채널·입력 | Hit@1 | Hit@3 | Hit@5 |
| --- | ---: | ---: | ---: |
| 일반 법령·질문 (47) | 15→16 | 22→28 | 24→33 |
| 일반 법령·문맥 (47) | 13→16 | 23→28 | 27→32 |
| 민법·질문 (32) | 12→10 | 15→13 | 반환 상한 3 |
| 민법·문맥 (32) | 11→11 | 14→13 | 반환 상한 3 |

일반 법령 평균 Hit는 상승했다. 그러나 **235입력 중 기존 일반 TOP3 필수 근거 손실 13입력**, 기존 일반 TOP5 필수 근거 손실 13입력이 있다. 두 목록을 합산하지 않는다. 별도로 기존 민법 TOP3 필수 근거 손실은 3입력이다. 일반 TOP5와 민법 TOP3를 합친 실제 반환 범위의 손실은 **총16입력**이다.

민법 전용 공개 35문항은 기존과 같이 고정 필수29개 중28개 완전 확보, 민법 Hit@3 29/29였다. 나머지는 범위 보류1개·진단5개다. 작은 기존 민법 세트가 유지돼도 넓은 DEV100에서 발생한 하락은 별도로 드러난다.

## 원인을 어디까지 좁혔나

누락을 **문항-필수 조문 쌍**으로 세면 다음과 같다. 한 문항에 여러 근거가 필요할 수 있어 위의 문항 수와 다르다.

| 입력·채널 | BM25/dense 후보에는 있으나 최종 범위 밖 | 구성원 후보에도 없음 |
| --- | ---: | ---: |
| 질문·일반 법령 | 35 | 4 |
| 문맥·일반 법령 | 37 | 5 |
| 질문·민법 | 24 | 0 |
| 문맥·민법 | 24 | 0 |

민법 진단은 허용된 **26개 전체 깊이**로 조회하므로 후보에 있었다는 사실만으로 좋은 검색 성능이라고 평가하지 않는다. 결합 순위와 최종 선택을 함께 확인해야 한다.

- **일반 법령의 결합 순위·후보 경쟁:** DEV-005의 주택임대차보호법 제3조는 BM25 2위·dense 16위지만 TOP5 밖으로 밀렸다. 신고·확정일자 절차 조문이 상위를 차지했다. DEV-044도 기존 핵심 조문이 BM25 2위인데 최종 TOP5에서 빠졌다. 초기 5개만의 실험에서 3→4위였던 문제가 전체 코퍼스에서는 더 커졌다.
- **민법의 기본 순위:** DEV-067의 제536조는 BM25 10위·dense 16위·결합 12위다. DEV-071의 제615·654조도 결합 13·10위로 낮다. 적재 누락이나 허용 목록 누락으로 설명할 수 없다.
- **신규 민법 확보 효과의 한계:** 추가16개 중 고정 필수 목표에 해당하는9개는 해당 DEV 입력에서 TOP3 반환이 한 건도 없었다. 새 민법이 다른 질문에 반환되는 것과 필요한 질문에서 올바른 목표를 확보하는 것은 다르다.
- **민법의 마지막 선택:** DEV-059의 제626조는 결합 3위였지만 기존 두 후보 보존 + 세 번째 의미검색 비중 조정 이후 반환에서 빠졌다. 질문 기준 민법 누락24쌍 중1쌍이 이 경우이며, 나머지23쌍은 결합 순위부터 낮았다.
- **보완 근거와 필수 근거의 구분:** 새로 검색된 확정일자·신고 관련 조문이 모두 무관하다고 단정하지 않는다. 다만 이들이 고정 필수 보호 조문을 대체할 수 있다는 정답 변경도 하지 않는다.

전수 누락 원인과 구성원 순위는 [분석 JSON](../data/eval/patch026-full/analysis.json), 원래 검색 순위는 [실제 결과](../data/eval/patch026-full/capture/after.json)에 남겼다. 일반 법령 결합 순위는 TOP5만 캡처했으므로 그 밖의 정확한 결합 순위는 추정하지 않는다.
