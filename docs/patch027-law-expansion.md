# PATCH-027 법령 확대·검색 보완

## 번호 정정

2026-09-13, 팀원 PR #24 (`8d3364b`)의 공유 `LIST.md`가 PATCH-026을 사용해 우리 미푸시 작업을 PATCH-027로 정정했다. 팀원26 행은 원문 그대로 유지한다. 이 시점 PR #24 코드는 아직 main에 병합되지 않았으므로 팀원 코드 통합 검증을 끝냈다는 뜻은 아니다.

기존 로컬27은 이 법령 확대 작업의 순위 실험을 잠시 분리했다가 로컬26에 합친 이력이었다. 이번에는 **같은 작업을27로 재개**하고 통합 방향을 정정한다. 무관한 작업에 취소 번호를 재사용하지 않는다.

- 활성 브랜치: `feat/patch-027-law-expansion`
- 이전 활성 브랜치: `feat/patch-026-procedure-law-expansion`

- 작업 폴더 `patch026-worktree`, `scripts/patch026_*`, `data/eval/patch026-*`, 원문 속 패치 표기는 과거 실행·해시의 식별자다. 측정 원본은 일괄 치환하거나 다시 생성하지 않는다.
- 현재 PR 초안: [patch027-pr.md](patch027-pr.md).

## 완료된 기반

61조문 추가 후보204조문, 민법26개를 같은235입력으로 평가했다. DEV100의 고정 필수 데이터 미보유32→0, 질문/문맥 완전 확보28→32 / 30→34. 기존 반환 범위의 필수 근거 손실16입력이 남아 운영 반영은 보류했다. [전체 코퍼스 분석](patch026-full-evaluation.md)을 기준으로 삼는다.

## 이번 비교를 실행 전에 고정

데이터204조문·질문235개·고정 정답·모델·출력 범위는 유지한다. 일반 법령과 민법은 각각 다른 채널의 현 상태를 유지한 비교로 먼저 평가한다.

일반 법령:
1. 주택/상가 임대차법과 두 시행령133개, 추가 일반 법령45개의 BM25 통계를 분리하고 원점수를 합친다.
2. 두 묶음에서 각각 BM25+dense를 결합한 뒤 같은 비중으로 합친다.
3. 위 두 방식에 기존 임대차 묶음의 선두1개 또는2개 보존을 각각 비교한다.

민법:
1. 현재 선택 결과를 기준으로 한다.
2. 전체26개에서 단순 RRF TOP3, 의미검색 비중2배 RRF TOP3를 비교한다.
3. 기존 주제 선택을 유지하되 나머지를 단순 RRF 또는 의미검색2배로 채우는 방식도 비교한다.

정책 이름과 개수는 실행 전에 코드에 고정한다. 특정 DEV 번호나 정답 조문을 선택기에 넣지 않는다. 원래133개 임대차 묶음의 결과가 보존된 기존 기준선과 일치하는지 함께 확인한다.

## 채택 기준

- 기존 일반 TOP3와 실제 반환 범위(일반5·민법3)의 필수 근거 손실0을 우선 확인한다.
- 현재204조문 결과보다 DEV 완전 확보가 질문32/75·문맥34/75 아래로 내려가면 채택하지 않는다.
- CIV35 고정 필수 확보28/29와 민법 Hit@3 29/29, 판례·안내 결과를 보존한다.
- Hit@1·3·5, 새 근거 확보, 기존 근거 상실을 모두 공개한다. 평균 점수만으로 개별 회귀를 덮지 않는다.
- 통과한 정책이 없다면 억지로 운영 반영하지 않고 남은 원인과 다음 설계 선택을 명시한다. 이것은 공개 개발 비교이며 독립 평가가 아니다.
