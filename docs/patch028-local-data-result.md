## 공유 대상 DB 잠금 리뷰 보완

- 저장소별 tmp 잠금을 실제 대상 DB의 `.retrieval-data.lock`으로 변경했습니다. 일반 설치·Django 관리 명령·검증 묶음 도구가 같은 경로의 OS 잠금을 사용하며, 다른 체크아웃도 동일 대상이면 거부합니다. 잠금 파일은 교체하거나 삭제하지 않습니다.
- 관련107개 통과. 실제 별도 Python 프로세스에서 잠금 충돌과 해제 후 재진입, 정규화된 경로 별칭, 다른 체크아웃의 구축 차단, 다른 대상 DB의 동시 사용을 검증했습니다. Windows에서 실행했으며 RunPod의 다중 Pod 동시 실행은 실측하지 않았습니다. 전체 테스트·DB 재구축·검색 평가는 반복하지 않았습니다.
