# PATCH-039 인용 근거와 강조 표기 검증

## 변경

검색된 청크 본문에서 발견한 조 번호를 모두 인용 허용 목록에 추가하던 동작을 수정했다. 현재는 청크의 `citation`이 지정하는 법령명·조·가지번호만 근거로 인정한다. `citation`이 없는 이전 형식은 본문 맨 앞의 `[법령명 제N조]` 헤더로만 식별하며, 일반 본문에서 출처를 추정하지 않는다. 여러 조문이 섞인 출처 표시는 확인 불가로 처리한다.

본문의 법령명은 이름 해석에 사용할 수 있지만 조문 근거 인정에는 사용하지 않는다. 교차참조 대상 조문이 별도로 검색되면 그 대상 청크의 ID로 인정한다. 일반 법령과 `civil_laws`에 같은 기준을 적용한다.

짝이 맞는 `*`, `**`, `***`, `_`, `__`, `___` 강조 구분자는 검사용 문자열에서 같은 길이의 공백으로 바꾼다. 법령명을 감싼 `「」`, `『』`도 처리한다. 원래 답변은 변경하지 않고 인용·항 오류의 `text`는 원문에서 잘라 기록한다. 법령명과 조 번호 사이에 강조 문자가 끼어도 인용을 추출하며, 강조한 잘못된 조문은 여전히 거부한다. 항 검증에도 같은 사본을 사용해 강조된 항·목록·범위가 검사를 건너뛰지 않도록 한다.

## PR #27 연속 인용 누락 정정

`04b7fdc` 리뷰의 P1 반례를 확인했다. `민법 제4조`만 검색된 상태에서 `**민법 제3조**과 **민법 제4조**에 따릅니다`를 하나의 인용으로 읽어 제3조가 검사에서 누락됐다. 일반 문장의 `민법 제3조와 민법 제4조`도 같은 문제가 있었다.

조 번호를 먼저 순서대로 찾고 각 조 번호까지로 법령명 추출 범위를 제한했다. 앞 조문을 뒤 법령명으로 흡수할 수 없으며 강조 처리의 원문 위치 보존은 유지한다. 인용 사이의 선행 연결어·항 표지를 법령명에서 분리하되, 실제 여러 단어로 된 법령명 내부의 `및`은 보존한다.

9개 표기 방식 × 5개 연결 표현 × 3개 근거 보유 조건에서 두 인용을 각각 확인한다. 다른 법령·가지번호·항 소속 및 chain/graph의 잘못된 앞 인용 보류도 검증했다. 같은 관련 테스트 명령으로 **366 passed, 6 subtests passed**, 위 UTF-8 전체 명령으로 **1,413 passed, 3 skipped, 172 subtests passed**를 확인했다. 생략 사유와 실제 LLM 미평가 범위는 초기 검증과 같다.

## PR #27 제목 속 조문 번호 정정

`citation_of()`가 만드는 `민법 제255조(「국가유산기본법」 제3조에 따른 국가유산의 국유)`에서 제목 속 제3조 때문에 주 출처인 민법 제255조도 거부되던 오류를 재현했다. 출처 표기의 유일성은 제목 앞 법령명·조 번호에서 검사하도록 수정했다. 항 검증의 출처 및 본문 맨 앞 헤더도 같은 식별 함수를 사용한다.

끝에 붙은 균형 잡힌 괄호 제목 하나만 분리한다. 제목 내부 중첩 괄호는 허용하지만 제목 뒤에 별도 조문이 이어지거나 괄호가 닫히지 않으면 출처가 모호한 것으로 처리한다. 제목에서 참조하는 조문은 검색 근거 목록에 추가하지 않는다.

실제 `citation_of()`로 만든 출처, 제목을 가진 이전 형식 헤더, 정상/없는 항, 모호한 다중 출처, chain/graph의 정상 답변 유지와 미검색 조문 보류를 추가했다. 관련 테스트 **387 passed, 6 subtests passed**, UTF-8 전체 **1,434 passed, 3 skipped, 172 subtests passed**. 생략 사유와 실제 LLM 미평가 범위는 앞선 검증과 같다.

## PR #27 복사한 출처명·표시 링크 정정

출처 색인에서만 제목을 제외하던 처리를 답변 경로에도 연결했다. `answer_citation_scan_text()`를 조문 인용 검증, 항 검증, 화면 인용 구간 추출에서 함께 사용한다. 검색 근거의 법령·조문 뒤에 그대로 복사된 제목만 비교해 가리며, 비교에는 강조 표지·법령명 따옴표·공백 차이만 허용한다. 원문과 문자 위치는 유지한다. 다른 제목, 떨어진 괄호, 제목 뒤에 별도로 주장한 조문·항은 계속 검사한다. 제목 속 참조 자체를 검색 근거로 인정하는 것은 아니다.

화면 링크도 공통 법령·조문 식별자를 사용한다. 분리된 강조 표기와 같은 조 번호를 가진 여러 법령을 정확한 청크로 연결하며, 명시한 법령이 미검색 상태이면 다른 법령의 동일 조 번호로 대신 연결하지 않는다. 법령명이 없는 조 번호만의 기존 표시 기능은 해당 조문 근거가 유일할 때 유지한다. 중첩 괄호 제목의 공식 링크 생성에도 동일한 제목 경계 검증을 적용했다.

`tests/test_citation_display_consistency.py`에서 프롬프트가 제공한 출처명 → 복사 답변 → 조문·항 검증 → Django 표시 구간·링크·발췌를 함께 확인한다. 실제 DB·LLM 대신 합성 근거와 가짜 LLM을 사용하며 chain/graph의 정상 응답 및 별도 미검색 인용 보류도 검사한다. 관련 **482 passed, 16 subtests passed**. 전체 UTF-8 **1,467 passed, 3 skipped, 172 subtests passed**. 생략 사유와 실제 LLM 미평가 범위는 앞선 검사와 같다.

## 영향과 남은 확인

### 업로드 문서 인용의 연결어 정정

공식 근거에 민법 제3조, 업로드 문서에 민법 제4조가 있을 때 `민법 제3조과 민법 제4조`의 두 번째 원문 인용에는 연결어가 남는다. 강조된 표현에서도 같으며, 이 원문을 그대로 문서에서 찾던 오류를 수정 전 회귀 검사로 재현했다.

`CitationMention.law_key`에 대조용 법령명·조 번호·가지번호를 보관하고 `text`는 표시·로그용 원문으로 유지한다. 업로드 문서에서도 같은 인용 파서로 식별자를 추출해 정확히 비교한다. 기존 공식 근거가 있으면 우선 유지하고, 문서에만 있는 인용은 해당 문서 청크로 연결하며 공식 근거나 화면 원문 링크로 승격하지 않는다. 판례·기관의 문서 대조 정책은 변경하지 않는다.

`tests/test_document_citation_identity.py`에서 과·와·및·또는·쉼표, 일반·별표·밑줄 강조, 다른 법령·시행령·가지번호, 미보유 인용 거부, 오류 원문 유지와 문서 간 격리를 확인했다. 조 번호 부분 일치(제4조/제40조/제4조의2)도 허용하지 않는다. 관련 **546 passed, 16 subtests passed**. 전체 UTF-8 **1,536 passed, 3 skipped, 172 subtests passed**. 생략은 기존 LangSmith 미설정 2건과 로컬 PDF 미지정 1건이다.

### 별도 보완 항목: 준용 관계 설명과 실제 답변 평가

- 현재 정책 유지: 검색된 A조 본문에 B조를 준용한다고 적혀 있어도, B조를 명시적으로 인용하면 B조 본문이 필요하다. 이번 문서 대조 수정에서 예외를 도입하지 않는다.
- 보완 검토 범위: 검색된 A조에 명시된 A→B 관계만 설명하는 경우와, B조의 구체적 내용·효과를 주장하는 경우를 구분한다. 실제와 다른 관계, 관계와 내용 주장이 섞인 문장도 회귀 대상이다.
- 금지: 본문에 나온 B조를 통째로 허용 목록에 추가하지 않는다. 안전한 구분이 입증되지 않으면 현 정책을 유지한다. 구현·채택 여부와 담당 범위는 후속 작업으로 결정한다.
- 별도 평가: 실제 27문항의 고정된 입력·근거·모델·설정으로 답변율·보류율·비용 변화를 비교한다. 이번 합성 근거 기반 회귀 검사로 실서비스 개선 수치를 대신하지 않는다. 현재 영향은 미측정이다.

교차참조 대상의 본문을 받지 않은 답변은 이전보다 보류될 수 있다. "A조가 B조를 준용한다"라는 관계 서술에서도 B조를 명시적으로 인용하면, 이번 정책은 B조 본문이 검색돼 있어야 인정한다. 해당 조문을 추가 검색하거나 확보한 A조를 중심으로 답하도록 하는 후속 판단이 필요하다. 임의로 LLM 의미 판정을 추가해 예외를 허용하지 않는다.

이는 조문 출처 검증이며 답변 내용 전체의 법적 타당성 보장이 아니다. 기존 업로드 문서 출처·판례·기관 검증 정책과 semantic judge 호출 조건은 유지한다. 리트리버·DB·모델·프롬프트는 변경하지 않았으며 검색 Hit@K 개선을 주장하지 않는다. 비용 감소는 1차에서 새로 차단되는 답변에 한정된 기대 효과이고 실측치는 없다.
