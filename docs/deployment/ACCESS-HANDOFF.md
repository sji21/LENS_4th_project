# GitHub 외 운영 인수인계

작성일: 2026-09-23 · PATCH-066

GitHub에는 코드·운영 설정 예시·절차가 있습니다. 운영을 맡는 팀원에게는 아래 접근 권한과 Git에서 제외한 자료를 별도로 인계해야 합니다. 이 문서는 인계 대상과 확인 방법을 정리한 자료이며, 실제 권한 부여나 비밀값 전달이 완료됐다는 뜻은 아닙니다.

## 서비스만 사용하는 팀원

- 접속 주소: https://d3kro62a2qvg04.cloudfront.net/
- 웹·검색은 AWS에서 실행합니다. AI 답변 생성은 외부 RunPod 연결이 필요하며 현재 재연결은 후속 작업입니다.
- 서버 키나 운영 DB 없이 서비스 계정으로 사용합니다.
- 구성과 검증 범위: [팀 설명 문서](aws-runpod-team-guide.md).

일반 법령·민법·안내·판례의 검색 원천과 운영 사용자 데이터는 용도가 다릅니다. 운영 EBS 전체를 팀 개발용 데이터 ZIP으로 배포하지 않습니다. 현재 작업에서는 대용량 데이터와 비밀값을 GitHub로 전송하지 않았고, 새 팀 데이터 ZIP도 발행하지 않았습니다. 기존 EC2의 검증된 데이터를 계속 사용합니다.

## 인계 완료 확인

1. 담당자가 서비스 주소, PR 브랜치, Python 3.11 실행 환경을 확인합니다.
2. 운영 담당자가 본인 계정으로 AWS·서버에 접근하고 서비스/백업 상태를 조회합니다.
3. 로컬 재현이 필요한 경우 공유받은 검색 release의 manifest와 모델을 검증합니다.
4. 비밀값 보관 담당자와 백업 복원 담당자를 정하고 제한된 채널에서 인계를 확인합니다.
5. RunPod 연결 후 실제 AI 질문·답변을 별도로 검증하고 당시 결과를 기록합니다.

권한 부여와 비밀값 전달에는 팀원 신원과 담당자 지정이 필요합니다. 이번 PR에서는 이 안내와 비밀값 없는 오프라인 공유 자료를 준비하며 실제 계정 권한을 새로 부여하거나 외부 메신저로 자료를 전송하지 않습니다.
