# PATCH-011 — DEV v2 근거와 조 단위 재대조 공유

리뷰2와 최소 보완으로 정답 근거의 역할·판본·조건이 바뀌었지만 자료와 재대조가 개인 폴더에만 있어 팀원이 같은 기준으로 검토할 수 없었다. 기존 v1을 보존하면서 [DEV v2 공유 자료](../data/eval/dev100-v2/README.md)와 모델/운영 DB가 필요 없는 재대조 도구를 추가했다.

## 변경 범위

- 제공 검토 원문 7개를 바이트와 해시로 보존한다. 리뷰2의 변경 100건 및 최소 보완의 28문항·55개 명제, 출처 101개를 공유한다.
- 질문 100개와 검색 입력 200개는 v1과 동일하다. v1의 파일과 해시는 바꾸지 않는다.
- 기본 필수 법령 목표를 `diagnostic-plan.json`으로 고정한다. 조건부·판례·기관 안내·개인 자료·과거 시점의 한계를 별도 보존하며 최종 문항별 합격식은 미동결이다.
- 저장된 PATCH-010 실행의 순위·입력 해시·본문 해시와 140개 법령 목록을 공개한다. 원래 저장 실행의 정확한 커밋은 미상이며 이후 14입력 재현의 커밋과 혼동하지 않는다.
- `scripts/dev100_v2/report.py`는 해시·ID·입력·본문/조 번호 일치를 검증한 뒤 저장 결과를 다시 분류한다. 새 검색이나 답변 생성은 하지 않는다.

제품의 검색·생성·적재 코드는 바꾸지 않았다. 운영 DB·법령 청크 본문·벡터·모델·개인 파일 경로·API 키도 공유하지 않는다. 원문 파일의 공식 URL과 짧은 근거 발췌는 검토 자료의 일부다. 원문에 남은 내부 웹 도구 참조는 독립 접근 가능한 원문 증빙으로 간주하지 않는다.

## 재현 및 검증

```powershell
.venv/Scripts/python scripts/dev100_v2/report.py --check
.venv/Scripts/python scripts/dev100_v2/report.py --out tmp/dev100-v2-report
.venv/Scripts/python -m pytest tests/test_dev100_v2.py -q
```

- 오프라인 재대조: 원문/자료 해시, 100문항·200입력, 140개 조문과 공개 결과 JSON 3개 일치 확인.
- 관련 테스트: 20 passed. 입력 변조·중복/누락·본문 불일치·가지조 유실을 거부하고, 일부 데이터 부족과 검색 누락의 병존·비법령 분리·과거 판본 보류·출력 덮어쓰기 방지를 확인한다.
- Git 스테이징 내용으로 만든 새 체크아웃에서도 해시/결과 재대조와 동일 테스트 20개가 통과했다. 원문 끝 공백까지 보존하기 위해 원문 경로에만 Git 공백 예외를 둔다.
- 검증 범위는 이번 평가 자료·도구에 한정한다. 제품 전체 테스트와 새 200입력 벡터 검색은 재실행하지 않았다.

중복 제외 미보유 기본 필수 조문은 35개다. 이는 전체 정답률·최종 적재량이 아니다. 목표가 없는 23문항을 성공 처리하지 않으며, 조문 반환이 항·호·예외·판본과 모든 판례/안내의 충족을 보장하지 않는다. v1의 모든 인용 역할을 합친 보유 집계와 수치 차이를 검색 개선으로 표현하지 않는다.
