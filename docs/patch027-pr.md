# PR 본문

## 목적과 변경

절차 법령 5조문을 기존 어휘 검색에 함께 넣으면 기존 근거가 밀립니다.
기존/절차 BM25 통계를 분리하고 원점수를 동일 비중으로 합친 뒤 기존 dense/RRF와
결합하는 후보를 구현했습니다. 일반 법령 TOP5와 민법·판례·안내 반환 계약을 유지합니다.
절차 데이터가 없는 기존 DB는 원래 검색기를 사용합니다.

PATCH-026에 의존합니다. PATCH-026을 먼저 병합한 뒤 이 브랜치의 PR을 main 대상으로
생성하거나, 그 전에는 PATCH-026 브랜치를 base로 한 의존 PR로 검토해야 합니다.
관련 GitHub 이슈는 없습니다.

## 비교와 검증

- 공개 개발 235입력: DEV100 질문/문맥 각 100 + 민법 35. 독립 평가가 아닙니다.
- 7개 정책 + 2개 대조군 비교. BM25 통계만 바꿔도 기존 필수 근거 손실 1개,
  신규 후보까지 혼합하면 6개였습니다.
- 구현 후보 실제 235입력이 저장된 비교와 모두 일치하며, 민법·판례·안내는 모두 보존됐습니다.
- DEV 필수 근거 완전 확보: 질문 28→29, 문맥 30→31. 일반 목표 47문항의
  Hit@3은 각각 22→26, 23→25이고 Hit@1은 15/47, 13/47로 유지됩니다.
- 전체 테스트: 877 passed, 3 skipped, 124 subtests passed.
- 공유 자료·검색 분리 관련 최종 테스트: 15 passed. 누락 파일/출처 의존성/중복 질문/
  잘못된 법령 식별자/다른 채널 변경을 검출합니다.
- `python -m scripts.patch027_report`로 DB·모델 없이 해시와 235입력 결과를 재집계합니다.
- 실제 실행 커밋 `34ea1f0`(clean), 원문/DB·인덱스 의미상 해시 보존.

## 중요한 한계와 반영 상태

**운영 데이터 추가 적재는 보류합니다.** 기존 필수 근거의 TOP5 손실은 0개지만
DEV-044 질문 입력에서 주택임대차보호법 제3조가 3위→4위로 이동합니다.
LLM이 법령 TOP3만 사용하면 영향을 받을 수 있으므로 TOP3까지 무손실이라고 보고하지 않습니다.
코드 후보와 실험 자료를 공유하는 PR이며 운영 DB·인덱스를 교체하지 않습니다.

서로 다른 BM25 코퍼스의 원점수는 보정된 점수가 아닙니다. 추가 절차 조문이나 새 질문에
대한 일반화 성능, 법률 정답의 독립 검증, LLM 답변 품질은 확인하지 않았습니다.
