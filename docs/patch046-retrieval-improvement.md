## 번호 정정과 재개 기준

이 작업은 2026-09-15 로컬에서 PATCH-042로 시작했으나, 원격에 다른 팀원의 `fix/patch-042-guide-citation-followup`이 먼저 등록됐다. 2026-09-16 원격 사용·예약 번호42~45를 확인하고 **PATCH-046**, 브랜치 `feat/patch-046-retrieval-improvement`으로 정정했다. 작업 폴더는 기존 `C:/team_project/patch042-worktree`를 유지한다.

기존 `patch042-*` 분석 파일·디렉터리는 로컬 분석 당시의 원본 식별자다. 원본 해시와 재현 의존성을 보존하며, 원격 PATCH-042 기관 인용 작업의 산출물이 아니다. 이후 개선 실측은 `patch046-*`로 기록한다. 새 검증은 최신 main `3eb534f`를 fast-forward로 반영한 미커밋 개선 소스를 사용한다. main에 포함된 생성 설정·기관 인용 수정은 다른 패치의 변경이며 이 검색 개선의 변경으로 집계하지 않는다.

## 변경 목적과 범위

체납 세금 조회 질문에서 국세·지방세의 법률과 시행령이 검색 후보에는 있으나 최종 일반 법령5개에 함께 포함되지 않는 문제를 보완한다. [개선 전 분석](patch042-retrieval-gap-analysis.md)과 고정 정답·평가 기준은 유지한다.

현재 질문에 체납·미납 조회 의도가 명시된 경우 기존 BM25+KURE 결합 TOP20 안에서 해당 세금의 미납·열람 표현이 본문에 있는 후보를 먼저 선택한다. 직접 일치 후보끼리는 기존 RRF 순서를 유지하고 남는 자리는 나머지 후보로 채운다. 평가 문항 ID·정답 조문 번호·특정 질문 전문을 사용하지 않는다.

- 국세·지방세를 명시하면 해당 종류를 구분한다.
- 인용·이전 대화만의 의도, 부정·조회 완료 표현, 환급·납부 확인 등 다른 세금 요청은 보수적으로 기존 검색을 유지한다.
- 전입·확정일자·계약 신고·반환·갱신·수리·경매·배당·사기·중개 등 다른 요청이 섞이면 기존 검색으로 돌아간다. 단어에 기반한 보수적 제한으로, 일부 실제 체납 조회 질문에도 개선이 적용되지 않을 수 있다.
- 기존 필터·후보 깊이20·반환 개수 일반5/민법3을 유지한다. 새 BM25·dense 호출, 자료·모델·민법 선택·생성 변경은 없다.
- 본문 단어 일치는 검색 우선순위 신호다. 열람 자격·동의 요건 등 법적 조건을 판정하거나 모든 문장 수준의 관련성을 보증하지 않는다.

제품 변경: `src/retrieval/multi_evidence.py`, `src/retrieval/expanded.py`.
