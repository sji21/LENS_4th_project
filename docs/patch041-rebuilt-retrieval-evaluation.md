### PR29 리뷰 보완

평가 기준 텍스트의 해시는 CRLF/CR을 LF로 정규화해 계산한다. Windows와 Linux 체크아웃의 줄바꿈 차이는 허용하며 실제 내용 변경은 거부한다. 원본 리뷰 번들의 manifest, 데이터·모델의 바이트 해시 검사는 유지한다.

`comparison.all_channel_ranking_changes`는 일반 법령·민법을 조문 식별자로, 판례·안내를 청크 식별자로 비교한다. 판례·안내의 순서나 반환 항목을 바꾸고 파일 해시만 다시 계산해도 이전 보고서의 재검증은 실패한다. 기존 `article_ranking_changes`는 법령 두 채널의 비교 의미를 유지한다.

첫 리뷰 수정 평가기로235입력을 다시 검색한 결과, 네 채널의 반환 근거와 채점 결과는 리뷰 전 실행과 동일했다. 최초 실행 원본은 구현 커밋 `8a57092`, 첫 리뷰 재실행 원본은 `241088f`에 보존된다. 공개 회귀78문항과 DB 구축 산출물은 기존 실행 기록을 유지하며 재실행으로 표현하지 않는다.

P2 보완은 [설정 기준](../scripts/patch041_settings_contract.py)을 별도 평가 소스로 고정한다. `settings_before`와 `settings_after`를 각각 실제 검색 직전·직후에 읽어 검증하고, 오프라인 검사에서도 두 기록과 기존 `settings` 필드를 모두 독립 기준과 대조한다. `settings`는 검색 후 설정을 유지한다. 검색 개수·프로필·코퍼스별 RRF·후보 깊이·BM25·질의 확장·가중치·민법 선택 설정의 누락·타입·값 변경을 거부한다. 감사 파일의 해시를 다시 계산하는 것만으로는 통과할 수 없다. 모델·DB를 불러오지 않으며 Python·장치 등 환경 기록을 동일하게 강제하지 않는다. 향후 의도적인 검색 튜닝은 이 PATCH-041 평가 기준도 검토 후 명시적으로 갱신해야 한다.

P2 수정 후의 새 235입력 실행도 이전과 반환 근거·점수·실제 검색 설정이 같았다. 이전 산출물은 `241088f`에 보존하고 현재 `capture`는 P2 수정 평가기의 새 실행 기록으로 교체했다.

LF·CRLF 체크아웃을 복제한 Windows 테스트로 재검증했으며, 별도 Linux 런타임 실행으로 표현하지 않는다. 재검색 일부 구간에 로컬 테스트가 함께 실행되어 지연 수치는 성능 비교에 사용하지 않는다.
